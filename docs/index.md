# slack

`slk` is a WireCat command-line tool for the terminal, for scripts and for AI agents.
It signs in to your Slack workspace as you, with the user token of a Slack app you make there, and its `api` group
reaches Slack's Web API, one command per method.

It has the commands every WireCat CLI shares: `doctor`, `commands`, `config`, `skill`, `mcp`, `runs` and `upgrade`,
and `session` to sign in.
Start with [installation](installation.md), then [usage](usage.md).
